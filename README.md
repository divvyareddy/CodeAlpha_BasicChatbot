# Basic Chatbot
## Description
This project is a simple rule-based chatbot developed using Python as part of the CodeAlpha Python Internship.
## Features
- Responds to "hello"
- Responds to "how are you"
- Responds to "what is your name"
- Ends the conversation when the user types "bye"
## Technologies Used
- Python
## How to Run
1. Open the project in VS Code.
2. Open the terminal.
3. Run the following command:
```bash
python main.py
```
